Important information

Refunds

  • Paid assets do not allow for a "try period" or something similar. Buying an asset means the customer knows what he or she is getting into. Because of this, it is highly recommend for the customer to ask about the asset as much as he or she wants. Any kind of resources (code, gifs, videos, images, etc) can be provided in order to make sure the customer is getting the asset he or she needs.
  • A refund will be authorized for you only if the asset advertises something that it is not. For example, if some feature is not there or doesn't even work. If that's the case, then you can send me an email and ask for a refund.
  • "I'm a beginner, sorry this asset is too much for me" or (the classic)"Sorry, my kid purchased your asset by mistake" or similar arguments like those will not be considered as valid arguments

Support

  • Support is free or charge.
  • Official support is given via email. Any other web site (forum threads, discord, social media, and so on) are not considered official support channels.
  • Support response tend to be relatively fast ranging from a day to three days. If you got the impression your message have been ignored, please send another email as a reminder.
  • It is always recommend to indicate the version of the asset you're using and your Unity editor version (if necessary).

Readme files

  • Every asset has some sort of "Readme" file in it, or even a "Welcome" window. A common problem among users is that they tend to ignore any setup instructions or readme, especially when there is demo content involved. Before asking for support, or even leaving a bad review, take a big breath and read the readme file that always comes with the asset (some). Don't worry, this won't make you lose your whole day, only half a minute.

Editor support

  • The minimum Unity editor version supported is the indicated on the asset store page. Never purchase an asset assuming it will work with older versions. That being said, most of these assets probably work with older versions of Unity. If you still want to use these assets with an unsupported version of Unity, please send an email to support.
  • New major updates of Unity not only bring new features, but also new bugs. Unfortunately for us publishers, our assets could be affected by this either directly (our assets stop working) or indirectly (some editor bug is making using the asset impossible). If any of this happens to you, the best thing you can do is to send me an email to support describing your situation.
